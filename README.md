# G検定 学習カード（Opus版の用語データ）

## 開くファイル

`docs/index.html` をブラウザで開いて使います。
ピンク色・キツネ・カードの配置・ボタンなどは元のHTMLを維持しています。

`docs` の中は、前のアプリと同じように役割ごとに分けています。

- `index.html`：最初に開く画面
- `styles.css`：色・文字・配置などの見た目
- `app.js`：527件の用語データと検索・学習記録の動作
- `.nojekyll`：GitHub Pagesでファイルをそのまま公開するための空の目印。開いたり編集したりする必要はありません。

公開するときは、この4つが入った **`docs` フォルダごと** アップロードしてください。
`index.html` だけを別の場所へ移すと、見た目や動作のファイルを読み込めなくなるので、3つの本体ファイルは同じフォルダに置きます。

## 今回の更新

- `G検定_用語マスター_Opus版.xlsx` の「01_用語マスター」から527件・9カテゴリを取り込みました。
- 用語、一言説明、試験での見られ方、似ている語との違い、20字暗記を、対応するカード項目へそのまま反映しています。
- 「20字暗記」は画面の「覚え方」に表示します。
- 同じ名前の用語も、Excelの行どおり残しています。並び順もExcelと同じです。
- 分野・優先度はカードデータに含めていますが、画面の構成を維持するため専用表示は追加していません。
- 混同ペア・逆引き・数理統計特訓・ダッシュボードなど、別シートの機能は今回追加していません。

元のHTMLとExcelは変更していません。更新版のカードデータには旧版の説明を混ぜていません。

## 学習記録

新版の進捗とメモは、旧版とは別に保存します。旧版の行番号と新しい用語を誤って結びつけないためです。
初回は未学習から始まります。旧版の記録を削除する処理はありません。
進捗とメモは端末・ブラウザ内に保存され、Excelには書き戻しません。

## 公開する場合

GitHubへは `docs` フォルダと、この `README.md` をアップロードします。
Pagesの設定は `main` ブランチの `/docs` です。Excelや確認用ファイルの公開は不要です。

## 更新・確認用ファイル

`update_from_excel.py` はExcelからHTMLを生成するための開発用スクリプト、`check-app.cjs` は動作確認用です。
通常の利用や公開では実行する必要はありません。
